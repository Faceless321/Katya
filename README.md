1. Запуск программы
Откройте файл movie_library.py
 двойным щелчком или через командную строку командой:
bash
python путь_к_файлу/movie_library.py
После запуска откроется окно приложения со всеми интерфейсными элементами.
2. Добавление нового фильма
Введите информацию о фильме в поля:
Название — название фильма
Жанр — жанр (например, комедия, фантастика)
Год выпуска — число (например, 2022)
Рейтинг — число от 0 до 10 (например, 8.5)
После заполнения нажмите кнопку «Добавить фильм».
Фильм добавится в таблицу ниже.
Поля автоматически очистятся для следующего ввода.
Совет: убедитесь, что год — число, а рейтинг — число в диапазоне 0–10, иначе появится сообщение об ошибке.
3. Просмотр списка фильмов
Все добавленные фильмы отображаются в таблице.
Можно щелкать на заголовки колонок, чтобы сортировать (при необходимости можно добавить такую функцию — но в этом примере сортировка не реализована).
4. Фильтрация фильмов
В верхней части под надписью «Фильтр по жанру» выберите интересующий жанр из выпадающего списка (например, «Комедия»). Или выберите «Все», чтобы снять фильтр.
Аналогично по году — выберите год (например, 2022) или «Все».
Таблица сразу покажет только те фильмы, которые соответствуют выбранным фильтрам.
Важно:
Если фильтры не нужны, нажмите кнопку «Сбросить фильтр» — оно уберет фильтр и покажет все фильмы.
5. Сохранение данных
Все введённые фильмы автоматически сохраняются в файл movies.json.
В следующий запуск программы данные загружаются из этого файла, так что фильмы не исчезнут при закрытии.
6. Дополнительные возможности
В любой момент можно добавить новый фильм, фильтры автоматически обновляются.
Чтобы добавить новые жанры или года, просто введите их при добавлении, они появятся в фильтрах.
Итог
Вводите фильм → нажимаете «Добавить фильм» → он появляется в списке.
Используйте фильтры для быстрого поиска нужных фильмов.
Всё хранится в JSON-файле, никаких дополнительных настроек или данных — всё просто и удобно!
